Role-Based Access Control (RBAC)

Simple permissions guide for FWC Admin Console

Super Admin

Full Platform Access (CRUD)

Has full CRUD control, direct publishing authority, approval/rejection power, sees the dashboard Pending Moderation queue, and manages admin users.

Content Admin

Creator & Recruiter

Can view dashboard metrics (will not see Pending Moderation), write/submit blogs & jobs for approval, and update candidate hiring statuses.

Analyst

Operational Reviewer

Read-only access across dashboard (will not see Pending Moderation), blogs, job listings, candidate lists, and client enquiries.

Quick Summary of Rules

  • • Dashboard & Pending Moderation: All roles can view dashboard metrics (traffic, visitors, conversions). However, the Pending Moderation card and queue is strictly visible only to Super Admin. Content Admin and Analyst will not see Pending Moderation on their dashboard.
  • • Client Enquiries: View-only for all roles (Super Admin, Content Admin, and Analyst) as it is strictly an inbound intake channel.
  • • Blog Posts & Job Listings: Super Admin has full CRUD (Create, Read, Update, Delete & Publish). Content Admin can view all, write, and submit for approval. Analyst has view-only access.
  • • Candidate Lists: Super Admin and Content Admin can view applicants and update hiring pipeline statuses. Analyst has view-only access.
  • • Approval Requests & Admin Management: Exclusively available to Super Admin.
